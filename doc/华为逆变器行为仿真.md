# 华为 V3.0 逆变器行为仿真

## 目标与范围

首版在已有 `huawei-v3.json` 点表上实现单台三相逆变器的控制闭环。保留原固定点表模板，新增 `huawei-v3-model.json` 行为模板；没有 `model` 的旧配置继续使用原取值引擎。

目标是按点表逐步完善较真实的设备行为，优先实现华为逆变器，再扩展其他设备。本次交付首版可运行效果，并非将最终目标限制为简单闭环。

点表依据为 `configs/inverters/huawei.md` 对用户提供的两份 V3.0 协议的逐点核验。地址、数据类型、倍率和功能码由该点表约束，不能通过点名猜测。机型 ID 沿用 50，组串数量仍沿用现有点表的四路；首版覆盖范围与后续待实现项如下。

## 模型与协议分离

- 设备模型内部采用 kW、kvar、V、A、Hz、kWh，独立按时间推进；读请求不决定设备运行速度。
- Modbus 适配层把模型状态映射到现有地址，按 Gain 编码，保持 AB/HL 及类型约束；同一响应采用同一状态快照。
- 模型参数与场景由 Web/API 配置：可用直流功率、电网线电压、频率、环境温度、效率。有功、无功、电流、电量等派生点禁止直接手改。
- 模型控制写入走统一校验和应用路径，Web 与 Modbus 具有相同效果。多字控制必须整点写入；批量写入先全部校验再生效。

## 首版行为

| 点表地址 | 行为 |
| --- | --- |
| 40125 | 有功百分比限值，raw/10 为百分比，范围 0～100 |
| 40120 | 有功固定值限值，raw/10 为 kW，范围 0～Pmax |
| 40126 | 有功固定值限值，raw 为 W，范围 0～Pmax |
| 40122 | 功率因数命令，raw/1000，合法区间 (-1,-0.8] 或 [0.8,1] |
| 40123 | Q/S 命令，raw/1000，范围 [-1,1] |
| 42017/42015 | P/Q 变化梯度，raw/1000 为 %/s，范围 0.1～1000 |
| 35300～35303 | 有功模式、模式相关设定值、最后使用的指令地址 |
| 35304～35307 | 无功模式、模式相关设定值、最后使用的指令地址 |
| 32080/32082/32084 | 统一计算的 P、Q、PF |
| 32064、32016～32023 | 直流输入功率与四路 PV 电压、电流保持一致 |
| 32066～32077 | 平衡三相电压、电流，与 P/Q 的视在功率一致 |
| 32106/32114/32078 | 根据实际 P 积分累计/当日电量，并更新当天峰值 |

在可用直流功率和转换效率约束下计算可用有功，按命令限值限制，再按梯度变化。Q 受点表最大馈入/吸收无功及 Smax 约束；首版采用有功优先。功率受限时状态1反映限电降额。可用功率降到零时进入待机。

行为模板的有功、无功梯度默认均为 100%/s（原始值 100000），控制面板待写入初值也为 100%/s。已有配置显式梯度保留；输入后点击“写入”才改变当前运行梯度。有功速度以 Pn、无功速度以 Smax 为基准，例如默认 50kW 设备从 49kW 降至 27.5kW 约需 0.43秒，网页每2秒刷新一次。

P 的三个入口、PF 与 Q/S 的两个入口分别采用“最后一个成功写入的命令生效”。这是明确的首版仿真策略，不能据此认定厂家所有固件均采用相同优先级。40125百分比以 Pmax 为基准，参照[华为2017协议](https://www.photovoltaikforum.com/core/attachment/87214-sun2000-v200r002-modbus-interface-definitions-pdf/) PDF第25页；该版本另有40118模式入口，不能把整套控制规则认定为2021 V3已确认。梯度分别以 Pn/Smax 为基准，属于尚待核实的仿真假设。同一批量帧包含多个模式命令时按地址顺序应用，避免 Go map 遍历引起随机优先级。

PF正设定对应正Q、负设定对应负Q；固定P模式暂采用35300=1、Q/S模式暂采用35304=2。这些符号及非零模式码是首版约定，需要原协议或实机核验。35305保留32位补码容器，负设定不能钳制为零。温度采用负荷相关的稳态温升，不代表厂家温控算法；电网电压/频率场景暂不触发厂家保护。

32089正常并网为已核验的0x0200；限电并网0x0201、限电停运0x0304、无光照待机0xA000参照同一2017协议PDF第11页，但该旧版状态地址是32287，因此用于32089属于明确的版本迁移假设。状态1的并网/限电/待机位按现有V3点表输出。已检查[华为2024协议](https://community.jeedom.com/uploads/short-url/cEJpNRU5j3k0LvPW43eRU7nKzfr.pdf) PDF第22/32页，未列32089完整枚举或353xx模式，不能据此补齐版本兼容性。

未实现的 RW 参数在行为模式下拒绝写入，并在网页说明，避免写入成功却没有效果。40200/40201 的有效命令值未明确，首版不增加。时钟设置、夜间无功、指令维持时间、Q-U 曲线、厂家保护策略、重启、电网潮流、其他设备均在后续范围。

## 时间与数据边界

- 固定最大 100ms 积分步长；采用仿真时钟，可注入时间做确定性测试。
- 当日电量以配置时区 43006 的本地日历切换，跨日正确分段；累计电量从模板初值起继续积分。
- 保存并应用配置会重建设备模型，重置临时命令/运行状态；首版重启后的电量由模板初值恢复，不承诺运行电量持久化。
- 华为行为模板和新添加设备的当日电量（32114）、累计电量（32106）默认初值均为 0 kWh，运行后按实际有功积分累加。读取已有配置时仍保留用户设定的电量初值。
- 原点表的身份、未建模告警、绝缘、时间等点保持模板值；网页说明覆盖边界。
- 当前模型能力满足0<Pn≤Pmax≤Smax，不设1～100kW/kVA业务限制，四路PV电压80～1500V；加载时校验协议寄存器编码范围，派生遥测超过类型范围时饱和，避免回绕。直流功率接受非负有限数值，不设100kW上限。

## 验收与测试

1. 默认额定容量和太阳可用直流功率均为 50kW，效率 0.98 时初始交流有功约 49kW，四路 PV 输入和三相输出的功率关系一致。
2. 从真实 Modbus 帧写 40125=500，P 按梯度逐步降至 27.5kW（Pmax=55kW）；353xx 更新为百分比模式和对应命令。
3. 写 40126=10000，切换固定值模式，P 收敛到 10kW；调光照后输出不超过可用功率。
4. PF/Q-S 命令影响 Q、PF 和三相电流；P²+Q² 不超过 Smax²，负值按 INT16 编码/解码。
5. 电量由实际输出随时间积分；不读取寄存器时仍推进；跨日清零当日项。
6. 非法范围、只读点、未实现命令、32位半点写入及混合非法批量写入不会改变任何命令。
7. Web 控制与 Modbus 走同一路径；网页可见目标与反馈，可调整场景查看变化。
8. 旧模板读响应回归不变；本地 Linux PTY 测试、Go race/vet 和前端测试通过。

实施采用先测试、再实现。远端部署与真实下位机端到端联调单独执行，本次优先提供本地网页效果。

## 查看效果

已有运行配置可以直接通过网页扩展：进入“RS485 配置”，在目标总线的“设备类型”中选“华为逆变器（V3，行为仿真）”，点击“添加设备”。完整点表和模型自动载入，站号自动避开已有设备；检查站号和环境初值后点击“保存并应用”。原从站和串口路径保留。同一路总线可新增多台华为，每台控制、环境和电量状态独立；选择“自定义 Modbus 设备”仍可手动配置任意点位。

模拟器进程使用独立行为模板启动：

```bash
./slavesim -config configs/inverters/huawei-v3-model.json -http :16000
```

浏览器访问对应主机的16000端口，运行页上方显示华为控制卡。先点击“50%限功率”，实际有功从约49kW按100%Pn/秒降低到27.5kW；点击“10kW”切换固定值；点击“PF0.9”观察无功、电流和功率因数联动。需要观察慢速斜坡时可写入更小梯度。修改太阳可用直流功率并点击“应用场景”，可观察光照变化约束。曲线只采集后端实际状态；页面不自行产生仿真数据。

RS485 配置的模型参数区直接提供“逆变器额定容量（kW）”。容量与相关寄存器初值联动，新设备直流输入默认等于额定容量；手动设置光照后保留自定义值。运行页固定有功范围随设备 Pmax 更新。详细边界见[逆变器容量配置](逆变器容量配置.md)。

保存配置会重建模型，临时控制/场景/电量恢复模板初值。Docker按原说明挂载配置目录，将行为模板复制为专用配置的config.json；现有运行配置需先备份，网页程序更新不会自动替换点表。

## 后续完善方向

华为为优先实现对象。下一阶段按同一份点表补齐已列出的时钟、夜间无功、维持时间、Q调整时间及保护参数；开停机有效写值、完整状态/模式枚举与厂家控制优先级需先核验对应协议版本。之后再扩展站级负荷、电表和其他品牌设备。每个点应明确分类为已建模、静态身份、待实现或缺少语义证据，避免将所有寄存器当作已经完整仿真的设备。
