# Web 多路 RS485 配置

## 目标与范围

在 slaveSim 自带 Web 页面维护完整的模拟器配置，支持多条独立 RS485 虚拟总线，每条总线挂多个 Modbus RTU 从站，每个从站维护独立寄存器点表。继续使用现有 JSON 结构和 PTY 通信，不引入真实串口驱动。

## 页面与接口

- 页面提供配置区域与现有运行状态、手动设值及报文日志。配置草稿不会被状态轮询覆盖。
- 总线支持新增、删除，编辑名称和稳定串口软链接路径；从站支持站号、响应延迟、未映射地址策略；寄存器支持功能码、地址、类型、访问权限、字节序、字序、BOOL 位号、点名、单位及全部数值来源参数。
- GET `/api/config` 返回当前完整配置；PUT `/api/config` 校验、保存并应用整个配置。成功后返回明确结果；非法配置、存储失败、创建串口失败时返回中文错误，尽量保持原配置和原运行状态。
- 更新同一路径总线的从站配置时保留 PTY；新增路径创建独立 PTY，删除路径释放 PTY。应用配置后该路手动覆盖值恢复为新配置的来源值。
- 同一路总线的站号不能重复，不同总线允许重复站号。总线名称、规范化后的串口路径不能重复；非法类型、寄存器重叠、32 位地址越界和非法来源参数均拒绝。
- 配置保存采用同目录临时文件和原子替换。容器需要可写配置目录挂载，不能继续使用只读单文件挂载；旧部署需更新 Compose 并重建模拟器容器。

## 异常与验收

- 空总线列表、空名称/路径、站号超范围、重复配置、错误 JSON 或尾随内容均不会覆盖原文件。
- 多路总线配置保存后 GET 和磁盘内容一致，重启模拟器后仍可加载。
- 同一串口路径更新从站后保留 PTY，新增/删除总线反映到状态和实际资源；并发轮询、手动设值与应用之间无数据竞争。
- 页面可配置全部来源类型（固定、手动、正弦、斜坡、随机），支持动态增删且保存失败时保留草稿并展示原因。
- 运行 Go 测试与静态检查、发布更新工具回归，检查浏览器交互。无法执行的环境检查必须注明。
